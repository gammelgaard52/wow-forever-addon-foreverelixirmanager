# CurseForge description

ForeverElixirManager prepares your next missing elixir in World of Warcraft:
Forever. It checks buffs and bags in a fixed order; you press one macro to use
one elixir. Nothing is consumed automatically.

- Six elixirs in a fixed priority order.
- Optional on/off choices saved per character.
- Simple list, buffs and status commands.
- Checks item availability and required level; pauses selection in combat.
- No aura-ID setup, priority editor or blocking rules.

**Experimental 0.4.0.** Buff detection assumes the original English buff names.
Different names, other locales and stronger/replacement effects are not handled;
disable affected entries. Item IDs, buff names, stacking and secure clicks remain
unverified in the live Forever client. See the repository README for installation,
the macro and limitations. Open source under the MIT License. Not affiliated with
Blizzard Entertainment.
